# 想看世界杯却进了医院？这个动作让他“漏气”了！

> 更新时间：2026-09-17 (UTC+8)

进球喽！

这几天，你走在大街小巷

是不是常会听到这样的欢呼声

四年一度的足球世界杯正在酣畅淋漓地进行中

今年22岁的杭州小伙小禹（化名）也是一位球迷

除了踢球，他还喜欢爬山、健身、跑步等运动

然而前阵子

他却因为运动进了急诊

这是咋回事？

**正在撸铁**

**却胸口一阵剧痛**

“本来和朋友约了一起看球，这下只能先乖乖在医院住院了！”22岁的小禹郁闷地说，虽然还是能通过手机看，但毕竟和朋友们一起欢呼着看的感觉差远了。

小禹是个球迷，也是个热爱运动的小伙子，大学时就爱和朋友们时不时来上一场友谊赛，工作后因为大家周末很难约起来，也就减少了踢球的次数。但随着四年一度的世界杯的到来，小禹和朋友们又“蠢蠢欲动”，约着要来切磋一下。

“好久没踢球了，得先去加强一下体能训练。”小禹便来到家附近的健身房，因为平时时常在运动，小禹自诩是“健身达人”，直接就开始“撸铁”，结果在举杠铃时，突然感觉到右胸部一阵剧痛。

  //  

糟糕，是不是没有做热身运动，导致肌肉拉伤了。小禹边想着，边赶紧停止运动，打道回府，想先休息一下。然而，三四个小时过去了，小禹右胸疼痛的情况不仅没有好转，还出现了胸闷的感觉。还是有一定运动知识的他，意识到自己肯定不是肌肉拉伤这么简单，就赶紧在家人陪同下来到了家附近的浙江大学医学院附属第一医院之江院区急诊科。

之江院区急诊科张小春医师接诊小禹后，询问病史，并做了快速床旁超声筛查，考虑小禹是右侧气胸，随后完善胸部CT检查证实，小禹被转到了普胸外科病房。

**原来是肺漏气了**

**剧烈运动是一大诱因**

 “通俗地说，自发性气胸就是肺上破了个洞，肺漏气了。”小禹的主管医生、普胸外科苗惠文医师说。

自发性气胸是指肺组织及肺胸膜的自发破裂，或胸膜下肺大疱自发破裂，使肺及支气管内气体进入胸膜腔所致。你可以把肺想象成一个气球，本来是完好无损所以可以正常放大缩小来工作，**但自发性气胸就是这个气球破了个洞，就不断漏气变小**，从而影响正常的呼吸功能，患者也就会感到胸痛、胸闷、喘不上气等情况，严重者甚至会威胁生命。

那为啥好好的肺会破洞？通俗地说，就像轮胎破洞一样，**因为各种原因，患者肺胸膜上有薄弱点**，然后在外力刺激下，比如剧烈运动、剧烈咳嗽等，就导致破洞了。**最经常导致“轮胎破洞”的原因就是肺大疱破裂**，人的肺部有很多小小的肺泡，通过气体内外交换给身体供氧，但是如果因为各种原因导致这些肺泡融合在一起，就变成了肺大疱，肺大疱的壁膜弹性要比正常肺泡壁差，就容易在胸腔压力突然变化时发生破裂。

所以，一般来说，**自发性气胸很容易找上瘦高体型的青少年**，因为青春期生长发育快，个子窜得快，胸部发育跟不上节奏，肺部就容易出现肺大疱。不过小禹是个身材非常健壮的小伙子，而且通过CT也并未发现他肺部有明显的肺大疱，专家判断，小禹先天性在肺上可能就存在薄弱点，然后举杠铃时他屏气，就导致气胸发生。

随后，普胸外科专家团队对小禹进行了胸腔引流等一系列治疗，小禹顺利康复，只不过，接下去半年，他都不能再进行大强度的运动，防止再次发生气胸，看来他只能暂时和足球拜拜了。

**运动有益身体健康**

**但也要注意安全**

“我们接诊到自发性气胸的患者，**有不少是在剧烈运动后发生的**。”普胸外科（三）主任徐鹤云主任医师说，“体型比较瘦高或者肺组织发育不良的人在健身等运动剧烈时，要特别注意。由于气胸发生之前没有迹象，比较难预防，**所以在剧烈运动、剧烈咳嗽、用力屏气、用力排便等情况下，如果发生胸部疼痛伴有胸闷、呼吸困难的情况，一定要及时就医筛查**。”

自发性气胸在及时治疗后，大部分人可以痊愈，一般先进行胸腔引流等保守治疗，如果肺上的洞无法自行愈合，那就需要进行微创手术“补胎”。如果病情较重或没有及时治疗的患者，则可能会因为纵隔移位等并发症导致急性呼吸窘迫症、循环衰竭、休克等，危及生命。

专家表示，虽然自发性气胸多见于体型瘦高的人，但不代表肥胖人群和健壮人群就不会得，像小禹就是身材健壮的健身达人。肺脏薄弱，如先天发育不良或合并肺大疱，在诱发因素下都可能会出现气胸。另外，得过气胸的人，在半年内要避免像提重物、屏气、举重、打篮球、足球等对抗性和需要突然发力的剧烈运动，防止复发。

近年来，随着大家对身体健康的不断追求，运动也越来越受到人们追捧，夏天的游泳、冬天的滑雪，还有马拉松、足球等，但是运动伤害、运动造成的意外等也时有发生，我们曾写过剧烈运动导致横纹肌溶解，也写过在长跑中突发心梗等，运动肯定是有利于身体健康的，但是我们更要健康运动、科学运动！
